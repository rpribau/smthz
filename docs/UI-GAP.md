Status: 2026-10-24, task `task_279149630b03`. Compares `Sources/SmthzApp/*` (4 files, 528 lines, read in full) with the Orca 1.4.238 spec in `docs/UI-SPEC.md`. Tags: `[verified]` = read in smthz or Orca source; `[inferred]` = not read or not rendered. The smthz app was **not** launched or screenshotted for this comparison; "how it looks" below is derived from the SwiftUI code and the macOS 26 default styling of the APIs it uses [inferred].

Section references like "§5.2" point into UI-SPEC.md. Decision IDs (D-CHROME, D-SIDEBAR, …) are listed in UI-SPEC §15; work that depends on one is marked **blocked by D-x**.

## 2. Proposed work packages

Principles: one bounded task per worker, disjoint file scopes, `Package.swift` touched by at most one WP (and only if the user approves bundling fonts/icons), each WP verified by the coordinator with build + full test suite + a real `open build/smthz.app` screenshot in light **and** dark mode compared against UI-SPEC values.

These WPs overlap with the M3 plan (`docs/M3-PLAN.md` WP-A2/A3/A4 already own `TerminalPaneHost.swift`, `TabStripView.swift`, `WorkspaceView.swift`, `WorkspaceWindow.swift`). ## 3. What the coordinator should check per WP

- Screenshot light and dark at 1440×900 and at 600×400; measure the 36/32/24 pt bands, sidebar 280 pt, tab width 180/220 pt, traffic light centre y = 18.
- Sample colours with the Digital Color Meter (Display P3 vs sRGB matters: compare in sRGB) against §1.1.
- Hover/active/focus states by real mouse input (AGENTS.md lesson: synthetic System Events clicks were unreliable; never type into another app).
- Reduce Motion / Reduce Transparency / Increase Contrast still work (DESIGN.md), Orca's reduced-motion rules (§1.5).

## 4. Not covered

Native chat, editor/diff, browser pane, kanban board, task pages, automations, activity page, floating terminal panel, jump palette contents and every Orca dialog body were not specified to the pixel; UI-SPEC lists only their shared primitives. They should get their own spec pass when their functional WPs start.
